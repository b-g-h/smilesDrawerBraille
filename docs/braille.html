Datenschutz

Diese Seite speichert keine personenbezogenen Daten auf dem Server. Im Browser werden folgende Daten lokal im localStorage gespeichert: die gewählte Theme-Einstellung (Hell/Dunkel), die OpenWebUI-Server-URL und ein verschlüsselter API-Key für die Scan-to-SMILES-Funktion. Diese Daten verlassen Ihren Browser nicht und können jederzeit durch Löschen des lokalen Speichers entfernt werden.

Beim Aufruf werden technisch bedingt IP-Adressen und Browser-Informationen vom Hosting-Anbieter GitHub Pages (GitHub Inc., USA) in Server-Logs verarbeitet. Diese Datenverarbeitung erfolgt auf Grundlage der GitHub Privacy Statement und der EU-US Data Privacy Framework Adequacy Decision. Es werden keine Cookies gesetzt und kein Tracking durchgeführt.
